# previous_temp — scratch / working files (not a study of record)

**What it is:** a mixed bag of intermediate outputs from the earlier **InOx** campaign and early
experiment02 exploration — trial ANOVA variants, GP diagnostics, and data-merge snapshots.

**Contents:**
- `L32_design_inOX_BEOL*.xlsx`, `sobol_example.xlsx`, `sobol_experiments.xlsx`, `new_design.xlsx` — old InOx L32 Taguchi / Sobol design drafts
- `master_df.pkl`, `master_iteration1.xlsx`, `master_xps_xrd.xlsx`, `XPS_XRD_with_newdata_clean.xlsx` — merged XPS/XRD data snapshots (InOx)
- `anova_*` (2-way interactions, Cook's-D filtering, significance comparison), `cv_percetage*.xlsx`, `ols_model_summary.xlsx`, `experiment_hall_stats.xlsx` — statistical trials
- `gp_*` (ARD/permutation importance, LOEO diagnostics, metrics) — early GP validation

**Vs the others:** working files only — no design here was fabricated from this folder, and every
analysis has a cleaner, final version in one of the study directories.
